# Tor Sustainability

## Data Provided

### Network Samples
We added the five 10% Tor network samples we used for our Shadow simulations, each named n(1-5).
Each network directory contains the cache files for the simulations results and the Shadow configuration files.

For the results we provide cache files of our results, we ran 24 hours of simulations for 5 selected configurations and one baseline configuration.

The Shadow configurations are named shadow.config.yaml# where # is (1-23) corresponding to the hour of the day. The file named shadow.config.yaml is the original config file generated by Tornettools, shadow.config.yaml# are generated from this base file. The configuration files are how we control the hourly workloads for the simulations.

We also provided the jupyter notebooks we used to analyze the provided data and to create the figures used in the our paper, for both the simulations and the open relay data.

### Open Relay Data
We provided the collected data from our three open relays. For safety concerns we release daily aggregate data. The data is under france/ germany/ and great-britain/

## Missing Data
We did not release the raw Shadow simulation data, mostly because of its size. The 24 hour data for one configuration alone takes 450GB, therfore we provide cached data files that can be used to re-create the figures in our paper.

We also did not release per second data from the open relays due to security concerns.
