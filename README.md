# Tor Sustainability

## Data Provided

### Network Samples

We provide the five 10% Tor network samples used for our Shadow simulations, each named `n1` through `n5`. Each network directory contains an `n#-configs/` folder with the Shadow configuration files and an `n#-results.zip` archive with the cached simulation result files.

For each network, we provide cached results for 24 hours of simulation across six configurations: one baseline and five carbon-aware configurations.

The Shadow configuration files are named `shadow.config.yaml#`, where `#` is an hour of the day (1–23). `shadow.config.yaml` (no suffix) is the original configuration file generated by Tornettools; the hourly files are derived from it and control the simulated workload for that hour.

### Carbon-Aware Relay Selection

`carbon-aware-calculation/` contains the script implementing our carbon-aware bandwidth-weighting formula, used to derive the five non-baseline configurations evaluated in the simulations.

### Notebooks

We provide the Jupyter notebooks used to analyze the provided data and generate the figures in our paper, covering both the simulation results and the open relay data.

### Open Relay Data

We provide data collected from our three open relays. For safety, we release only daily aggregate data, found under `open-relay-data/`.

## Missing Data

We do not release the raw Shadow simulation data, primarily due to its size — the 24-hour dataset for a single configuration alone is approximately 450GB. Instead, we provide the cached data files needed to reproduce the figures in our paper.

We also do not release per-second data from the open relays, for security reasons.
